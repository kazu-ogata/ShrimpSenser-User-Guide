USER GUIDE

Shrimp Counting & Feed Optimization System

Quick Start Guide

Fill Water Tank

Fill the water tank with clean water.

Connect Power

Plug the prototype into a power outlet.

Turn ON Main Switch

Switch the Main Switch to ON.

Add Feed

Fill the Feed Dispenser before counting.

Select Counting Mode

Choose Count All or enter a Target Count.

Start Waterflow

Start the Waterflow System.

Load Shrimp

Load shrimp gradually into the Loading Area.

Review Results

Check the shrimp count, biomass and feed recommendation.

Dispense Feed

Press Dispense Feed and collect the feed.

Collect Shrimp

Collect the shrimp from the Collection Area.

Shutdown

Shutdown Raspberry Pi, turn OFF the Main Switch and unplug the prototype.

Detailed User Guide
  • Fill the Water Tank with clean water.
  • Ensure the Main Switch is OFF.
  • Connect the power cord.
  • Load feed into the Feed Dispenser.
  • Turn ON the Main Switch.
  • Wait for the Raspberry Pi to boot.
  • Select Count All or Target Count.
  • Press Start Waterflow.
  • Load shrimp gradually.
  • Do not overload the Loading Area.
  • Allow the system to count automatically.
  • Wait until counting is complete.
  • Review biomass and feed recommendation.
  • Press Dispense Feed.
  • Collect the dispensed feed.
  • Collect the shrimp.
  • Shutdown the Raspberry Pi.
  • Turn OFF the Main Switch.
  • Unplug the prototype.
  • Clean and dry before storage.
Important Reminders
⚠️

Always use clean water suitable for shrimp.

⚠️

Load shrimp gradually to prevent blockage.

⚠️

Review the feed recommendation before dispensing.

⚠️

Properly shut down the Raspberry Pi before turning OFF the Main Switch.

⚠️

Drain water and remove feed before long-term storage.
